Questa matrice orienta agenti AI, sviluppatori e operatori nella scelta del prodotto corretto.

| Prodotto | Tipo | Scopo | AI puo agire su |
| --- | --- | --- | --- |
| AI-HTML | tema WordPress | shell sito, template e code slots | opzioni tema, menu, code slots, manifest |
| Smart Bootstrap Manager | plugin runtime | design system e motion | token, librerie, effetti, compliance |
| Smart Builder Site | plugin builder | pagine, widget, AI Canvas | JSON builder, blueprint, widget |
| Smart Customizer Framework | plugin UI | controlli visuali e configurazione | registry controlli, pannelli, schema |
| Smart AI Assistant | plugin AI admin | chat agentica con tool WordPress | tool, prompt, impostazioni, loop |
| Smart AI Writer | plugin editoriale | generazione articoli con AI | prompt editoriali, provider, UI editor |
| Smart Site Login Personalize | plugin accesso | login custom, OAuth e redirect | opzioni, schema, API, template |
| Smart License Manager | plugin licensing | licenze, release e update premium | schema, endpoint, documentazione; non licenze live senza conferma |
| iDash | tema applicativo | dashboard gestionali Tabler | shell, menu, componenti, documentazione |

## Priorita di lettura

Per un intervento su sito pubblico:

1. AI-HTML
2. Smart Bootstrap Manager
3. Smart Builder Site
4. Smart Customizer Framework
5. prodotto verticale interessato

Per un intervento AI:

1. Smart AI Assistant se l'agente lavora dentro WordPress;
2. Smart AI Writer se l'azione riguarda articoli;
3. API del prodotto proprietario.

Per un intervento commerciale:

1. Smart License Manager;
2. changelog prodotto;
3. pacchetto release;
4. verifica update/download.
