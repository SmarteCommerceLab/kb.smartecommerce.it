Smart AI Writer e un plugin WordPress autonomo per generare e modificare articoli con AI direttamente dall'editor.

## Funzioni

- generazione titolo, riassunto, contenuto o articolo completo;
- chat contestuale editoriale;
- anteprima testuale prima dell'applicazione;
- supporto editor a blocchi e Classic Editor;
- provider OpenAI e Anthropic;
- istruzioni editoriali configurabili;
- API key conservata lato server;
- nonce, capability check e sanitizzazione.

## Installazione

1. Copiare `smart-ai-writer` in `wp-content/plugins/`.
2. Attivare Smart AI Writer.
3. Aprire Impostazioni > Smart AI Writer.
4. Configurare provider, modello e API key.
5. Aprire o creare un articolo.

## Regole per AI

Il plugin genera bozze: non pubblica automaticamente. Una AI deve proporre, applicare su richiesta e lasciare il salvataggio/pubblicazione a un flusso esplicito.
